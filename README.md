
## Installation

1. Clone the repository:
  ```bash
  git clone <repository-url>
  cd SinergiaManager/Front
  ```

2. Install dependencies:
  ```bash
  npm install
  ```

## Running the Project

- Start the development server:
  ```bash
  npm run dev
  ```

- Build for production:
  ```bash
  npm run build
  ```

- Preview the production build:
  ```bash
  npm run preview
  ```
